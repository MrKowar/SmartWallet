# SmartWallet 1.2: подпись, обновления «по воздуху», ИИ-прокси

## 1. Ключи — сделайте резервную копию
Папка `C:\Users\alex2\SmartWalletKeys`:

| Файл | Зачем | Если потерять |
|---|---|---|
| `private_key.txt` | выпуск ключей активации и подпись обновлений интерфейса | нельзя выпускать ключи и обновления для текущих версий |
| `release.jks` | подпись APK (пароль — в `local.properties`, `release.store.password`) | новые APK не встанут поверх старых, у покупателей сменятся коды устройств |

**Код устройства зависит от ключа подписи APK.** Продавайте только release-сборки, подписанные `release.jks`.
Debug-сборка из Android Studio — это «другое приложение» с другими кодами устройств.

### Переход вашего телефона на release-сборку
1. В приложении: ⚙️ → «💾 Сохранить копию данных».
2. Удалите старое приложение, установите release-APK.
3. ⚙️ → «📂 Восстановить из копии».
4. Код устройства станет новым — выпустите себе ключ заново (`tools\keygen.bat issue <код>`).

## 2. Как выпустить обновление
```bat
tools\publish.bat --version-code 3 --version-name 1.2 --changelog "Кредиты, калькулятор и трекер погашений"
```
Скрипт соберёт подписанный APK и положит в `dist\` три файла:
`SmartWallet-1.2.apk`, `web-bundle.zip`, `update.json`.
Загрузите все три в GitHub Release с тегом `v1.2` (команду `gh release create …` скрипт напечатает,
или вручную на https://github.com/MrKowar/SmartWallet/releases/new).

Приложение читает
`https://github.com/MrKowar/SmartWallet/releases/latest/download/update.json`
**в фоне раз в 6 часов, даже если его не открывали** (JobScheduler), при запуске
и по кнопке ⚙️ → «🔄 Проверить обновления»:
- **новый APK** (`versionCode` больше установленного) — скачивается, сверяется SHA-256
  и ставится через PackageInstaller:
  - если пользователь уже разрешил «Установку из SmartWallet» и Android 12+ — **ставится сам,
    без вопросов** (после первого обновления через SmartWallet приложение становится
    «установщиком» самого себя);
  - если Android просит подтверждение — приходит уведомление «Обновление готово, нажмите,
    чтобы установить»;
  - если разрешения ещё нет — уведомление «Доступно обновление», в приложении окно
    с кнопкой «Обновить» и переходом в настройки разрешения.
- **новый интерфейс** (`web-bundle.zip` для этой же версии APK) — ставится тихо и включается
  при следующем запуске. Архив подписан `private_key.txt`, чужой архив приложение не примет.

### Только интерфейс, без нового APK
Поменяли только `index.html`? Тот же `versionCode`, `--web-version` на 1 больше, новый тег:
```bat
tools\publish.bat --version-code 3 --version-name 1.2 --web-version 2 --tag v1.2-web2 --apk-tag v1.2 --changelog "Исправления интерфейса"
```
В релиз `v1.2-web2` загрузите только `web-bundle.zip` и `update.json` (APK остаётся в `v1.2`).

⚠️ Репозиторий публичный: исходники и APK видны всем. APK без ключа активации не работает,
но если хотите скрыть код — сделайте `SmartWallet` приватным, а релизы публикуйте в отдельном
публичном репозитории и поменяйте `update.manifest.url` в `local.properties`.

## 3. ИИ через прокси (ключ Gemini не попадает в APK)
Сейчас ключи ИИ из `local.properties` **вшиваются в APK**, и их можно извлечь.
Прокси на Cloudflare Workers (бесплатно, 100 тыс. запросов в сутки) это исправляет:

1. Зарегистрируйтесь на https://dash.cloudflare.com и установите Node.js (для `npx wrangler`).
2. В папке `tools\ai-proxy`:
   ```bat
   npx wrangler login
   npx wrangler kv namespace create RATE_KV
   ```
   Впишите выданный `id` в `wrangler.toml` (раскомментируйте блок `kv_namespaces`).
3. Секреты (ключ — в Google AI Studio, бесплатный тариф):
   ```bat
   npx wrangler secret put GEMINI_API_KEY
   npx wrangler secret put OPENROUTER_API_KEY   (необязательно, запасной)
   npx wrangler deploy
   ```
4. В `local.properties` добавьте адрес, который выдал `deploy`:
   ```
   ai.proxy.url=https://smartwallet-ai.<ваш-аккаунт>.workers.dev
   ```
   После этого release-сборка **не содержит** ключей ИИ — все запросы идут через прокси.

Лимиты: с действующим ключом SmartWallet — 100 запросов в сутки на устройство,
в пробном периоде — 15 (`DAILY_LIMIT_*` в `wrangler.toml`). Прокси проверяет ключ
активации тем же открытым ключом, что и приложение.

В ИИ уходят только суммы (бюджет, категории, кредиты, цели) — без названий операций
и текста уведомлений. Денежные расчёты ИИ не делает: их считает `LoanCalculator`.
