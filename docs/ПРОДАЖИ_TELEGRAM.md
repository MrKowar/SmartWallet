# Продажа SmartWallet через Telegram

Группа для покупок: https://t.me/+vVnx3FwEgZM0MTYy
(ссылка зашита в `LicenseManager.BUY_URL`, кнопка «Купить в Telegram» на экране активации).

## Как это работает для покупателя

1. Устанавливает APK. Первые **7 дней** приложение работает бесплатно.
   Во время пробного периода раз в день при запуске показывается экран
   активации с кнопкой «Продолжить бесплатно».
2. На экране активации видит **код устройства** вида `ABCD-EFGH-JKLM` и копирует его кнопкой 📋.
3. Нажимает «Купить в Telegram», пишет вам в группе, отправляет код и оплачивает.
4. Получает от вас ключ `SW-…`, вставляет его и нажимает «Активировать».

После 7 дней без ключа приложение открывает только экран активации.
Все данные пользователя при этом сохраняются и появятся сразу после активации.

## Как выдать ключ (для вас)

Нужна Java 11+ (уже установлена: `java -version`). Команды запускаются из папки проекта.

```bat
tools\keygen.bat issue ABCD-EFGH-JKLM          :: навсегда
tools\keygen.bat issue ABCD-EFGH-JKLM 30       :: на 30 дней
tools\keygen.bat issue ABCD-EFGH-JKLM 365      :: на год
```

Скрипт выведет ключ `SW-…`, его и отправляете покупателю.
Ключ работает **только на устройстве с этим кодом**, поэтому делиться им бесполезно.

## ⚠️ Закрытый ключ

- Лежит в `C:\Users\alex2\SmartWalletKeys\private_key.txt`.
- **Сделайте резервную копию** (флешка, менеджер паролей). Если файл потеряется,
  новые ключи для текущих сборок выпустить будет нельзя: придётся создавать новую пару
  (`tools\keygen.bat init` после удаления старой), менять `PUBLIC_KEY_BASE64`
  в `LicenseVerifier.kt` и выпускать новую версию приложения.
- **Никому не отправляйте** этот файл и не кладите его в git: кто им владеет, тот может выпускать ключи.
- Открытый ключ (`public_key.txt`) секретом не является, он уже встроен в приложение.

## Частые ситуации

| Ситуация | Что делать |
|---|---|
| Покупатель сменил телефон | Код устройства будет другим. Выдайте новый ключ на новый код. |
| Покупатель переустановил приложение | Обычно код не меняется, подходит старый ключ. Если изменился — выдайте новый. |
| Сброс телефона к заводским настройкам | Код меняется, нужен новый ключ. |
| «Ключ не подходит» | Проверьте, что ключ выпущен на тот же код, что сейчас показан на экране, и скопирован целиком. |
| Истёк ключ на N дней | Выдайте новый ключ на тот же код. |

## Защита и её пределы

- Подделать ключ без закрытого ключа невозможно (подпись ECDSA P-256).
- Перевод часов назад не продлевает пробный период и срок ключа:
  приложение запоминает самое позднее время, которое видело.
- Пробный период можно начать заново, если очистить данные приложения
  (при этом пропадут и все записи пользователя). Без своего сервера это не закрыть.
- APK можно взломать, модифицировав код. Усложнить это поможет обфускация R8
  (`isMinifyEnabled = true` в `app/build.gradle.kts`); сейчас она выключена.

## Рекомендации по продажам в Telegram

- **Закреплённое сообщение в группе**: что умеет приложение, 3–4 скриншота,
  цены, APK файлом, инструкция «скопируйте код → напишите мне → получите ключ».
- **Тарифы**: например, месяц (ключ на 30 дней) и «навсегда» (бессрочный ключ).
  Цена «навсегда» ≈ 4–6 месяцев подписки, тогда её выгодно брать.
- **Оплата**: сейчас вручную (перевод по номеру или Telegram Stars).
  Следующий шаг — бот, который принимает оплату в Telegram Stars
  (для цифровых товаров Telegram требует именно Stars) и сам выдаёт ключ.
  Логику выпуска ключа можно взять из `tools/KeyGen.java`.
- **Google Play**: если когда-нибудь будете публиковать приложение там,
  продажа ключей в обход Google Play Billing нарушает правила магазина.
  Для продажи через Telegram распространяйте APK напрямую.
